# ⚡ Loading Animations Gallery – 24 CSS & SVG Patterns

A modern gallery of **24 unique loading animations** built using **CSS and SVG**.  
This project showcases creative loader designs with **global animation controls**, making it easy to preview, customize, and reuse loading animations in web projects.

---

## ✨ Features

- 🎨 24 unique loading animations
- ⚡ Built with pure **CSS and SVG**
- 🎛 Global animation controls
- 📱 Responsive layout
- 💡 Clean and modern UI
- 🧩 Easy to integrate into any project

---

## 🛠 Technologies Used

- HTML5
- CSS3
- SVG
- JavaScript (for global controls)

---

## 🚀 How to Use

1. Download or clone the repository
2. Open `index.html` in your browser
3. Browse and test the loading animations
4. Copy any loader and use it in your project
